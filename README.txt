Gearwise 0.1.0 - Author / Autor: Rottgar
Retail (Midnight), WoW: Forever, Mists Classic, Cata Classic, TBC Anniversary, Classic Era

ENGLISH
Simulates your character (DPS for damage dealers, HPS for healers, effective health and
mitigation for tanks) and shows on every item whether it is an upgrade, like Pawn.
Green arrow up = upgrade, red arrow down = downgrade, gold arrow up = upgrade for another
of your specs. One tooltip line per specialization. English and German.

Installation: copy the "Gearwise" folder to World of Warcraft/_retail_/Interface/AddOns
(or _classic_, _classic_era_, _anniversary_, _forever_ for the other game versions).

Commands
  /gearwise            window            /gearwise options     options
  /gearwise spec 1-4   set spec          /gearwise reset       spec back to automatic
  /gearwise arrows     bag arrows        /gearwise minimap     minimap button
  /gearwise language en | de | auto

DEUTSCH
Simuliert deinen Charakter (DPS für Schadensklassen, HPS für Heiler, effektive Lebenspunkte
und verhinderter Schaden für Tanks) und zeigt wie Pawn an jedem Item, ob es eine Verbesserung ist.
Grüner Pfeil nach oben = Verbesserung, roter Pfeil nach unten = Verschlechterung, goldener Pfeil
= Verbesserung für eine andere deiner Spezialisierungen. Eine Tooltip-Zeile pro Spezialisierung.
Deutsch und Englisch.

Installation: Ordner "Gearwise" nach World of Warcraft/_retail_/Interface/AddOns kopieren
(bzw. _classic_, _classic_era_, _anniversary_, _forever_ für die anderen Spielversionen).

Befehle
  /gearwise            Fenster           /gearwise options     Optionen
  /gearwise spec 1-4   Spec setzen       /gearwise reset       Spec wieder automatisch
  /gearwise arrows     Taschenpfeile     /gearwise minimap     Minimap-Button
  /gearwise sprache de | en | auto
